# 使用說明

Translation Magic Window 是一個「翻譯透鏡」：把它放在漫畫、遊戲或網頁上，透鏡底下的日文、英文、韓文會自動翻譯成繁體中文。

> 資料會送到哪裡，請見[隱私說明](privacy.md)。

## 開始使用

1. 啟動後，畫面上會出現一個有邊框的透鏡，右下角的系統匣有程式的圖示。
2. 拖動透鏡**左上方的把手**移動透鏡，拖動**邊框或角落**調整大小。透鏡裡面的區域點擊會穿透，照常操作底下的程式。
3. 把透鏡框住要翻譯的文字，畫面停下來一下子就會自動翻譯：
   - 預設是**結果視窗**：原文和譯文成對列出，可以調字級、勾「置頂」。
   - 打開系統匣的「**在原位顯示譯文**」，譯文會直接蓋在原文上（見下面）。
4. 點一下系統匣圖示可以藏起或叫出透鏡；藏起來時完全不會擷取或翻譯。

邊框的顏色代表狀態：拖動中、等畫面停下來、處理中、顯示結果中各有不同的顏色。

## 系統匣選單

| 項目 | 用途 |
|---|---|
| 顯示透鏡 | 藏起或叫出透鏡 |
| 在原位顯示譯文 | 譯文直接蓋在原文上 |
| 開啟結果視窗 | 看翻譯過的所有內容 |
| 立即翻譯 | 不等畫面停下來，現在就翻（快捷鍵 `Ctrl+Alt+Shift+T`） |
| 暫停 | 暫時不自動翻譯 |
| 漫畫模式（依對話框分段） | 同一個對話框裡的字當成一段來翻，直排的對白讀得更準 |
| 遊戲模式（只看文字區域） | 只在文字的地方有變化時才重翻，角色的動畫、閃爍的游標不會干擾 |
| 情境 | 漫畫、遊戲、網頁各記一組設定，切換時一起換（見下面） |
| 辨識語言 | 自動判斷，或固定日文、英文、韓文 |
| 編輯專有名詞表… | 人名、地名的固定譯法（見下面） |
| 設定… | 翻譯引擎、字型、快捷鍵等 |
| 除錯傾印 | 遇到問題時把當下的狀況存成一個資料夾，方便回報（快捷鍵 `Ctrl+Alt+Shift+D`） |
| 除錯覆蓋框 | 在透鏡上畫出辨識到的文字框和耗時 |

## 在原位顯示譯文

打開後，譯文會蓋在原文的位置上：

- 顏色照著原文：深色底白字、黃色的名字還是黃色，有描邊的字也畫描邊。
- 直排的對話框，譯文也直排。
- 字的大小自動配合原本的框。
- 作者刻意的特殊讀音（ルビ），譯文也用小字標在旁邊。
- **畫在圖上的字（擬聲詞、招牌）不蓋**，免得蓋出一塊突兀的色塊；它們的譯文在結果視窗裡。
- 畫面一動（捲動、翻頁、拖動透鏡）譯文會先消失，停下來再換上新的，不會留下錯位的字。

譯文的字型可以在「設定 → 譯文字型」換成思源黑體、思源宋體或 jf open 粉圓（要先下載，見 README）。

## 翻譯引擎

在「設定」選：

- **Google 翻譯**：預設，不用金鑰，但品質比 LLM 差。
- **其他引擎**：OpenAI 相容的 LLM（包括本機的 Ollama）、Claude、DeepL、Microsoft Translator、Google Cloud Translation，或自訂的 HTTP 服務。需要金鑰的填在「金鑰」欄，會加密存在你的電腦上。
- 勾選「失敗時改用 Google」，主要的引擎連不上或額度用完時會自動改用 Google，結果視窗會說明原因。

## 情境

系統匣的「情境」選漫畫、遊戲或網頁，每個情境記住自己的漫畫模式、遊戲模式、辨識語言、「碰到透鏡邊緣的句子翻不翻」、「畫面停下來多久才翻」。第一次切到某個情境時用適合它的預設值，之後在設定裡改的就記在目前的情境裡。

## 專有名詞表

系統匣的「編輯專有名詞表…」會用記事本打開 `glossary.txt`，一行一個詞，寫成 `原文=譯文`：

```
悠真=悠真
エクスカリバー=王者之劍
```

存檔後下一次翻譯就會生效。只有 LLM 引擎（OpenAI 相容、Claude）會照表翻譯。

## 快捷鍵

在「設定 → 快捷鍵」可以改。點一下欄位，直接按想要的組合；清掉代表不使用。要有 Ctrl、Alt 或 Win，再加一個字母、數字或 F 鍵（F 鍵可以單獨用）。

## 遇到問題

1. 按 `Ctrl+Alt+Shift+D`（除錯傾印），會開啟一個資料夾，裡面有當下的畫面、辨識到的文字、設定（不含金鑰）和記錄檔。
2. 檢查裡面沒有你不想給別人看的內容後，壓縮寄給開發者。

記錄檔預設不會寫入辨識到的文字。需要的話，在設定打開「詳細診斷」。
