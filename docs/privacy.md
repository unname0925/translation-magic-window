# 隱私說明

Translation Magic Window 會讀取透鏡底下的畫面，把上面的文字翻譯成繁體中文。這份說明列出哪些資料會離開你的電腦、哪些只留在本機。

## 一句話版本

- **畫面截圖不會傳到任何地方**。文字辨識（OCR）完全在你的電腦上進行。
- **辨識出來的文字會送到你選的翻譯引擎**。預設是 Google 翻譯；選本機的 LLM（例如 Ollama）時，文字不會離開你的電腦。
- 金鑰加密後存在你的電腦上，只會送給它所屬的翻譯服務。

## 會送出去的資料

除了每天檢查一次新版本（見下面），只有「翻譯」這一步會連上網路，送出的內容依引擎而不同：

| 引擎 | 送出的內容 | 送到哪裡 |
|---|---|---|
| Google 翻譯（預設，不用金鑰） | 要翻譯的文字、原文語言 | Google（`translate.googleapis.com`） |
| OpenAI 相容的 LLM、Claude | 要翻譯的文字、前面幾段的原文和譯文（讓翻譯前後一致）、專有名詞表裡**出現在這次文字中**的詞 | 你在設定裡填的網址；Claude 是 Anthropic |
| DeepL | 要翻譯的文字、前面幾段的原文（當作參考） | DeepL |
| Microsoft Translator、Google Cloud Translation | 要翻譯的文字 | Microsoft、Google |
| 自訂 HTTP | 你在請求範本裡放進去的內容（文字、語言、金鑰） | 你填的網址 |

- 填的網址是 `127.0.0.1` 或 `localhost`（例如本機的 Ollama）時，資料不會離開你的電腦。
- 各翻譯服務如何處理收到的文字，依各服務自己的隱私政策。
- 沒有文字的段落（例如只有數字的 `110/110`）不會送出；翻過的句子會記在記憶體裡，畫面上再出現時不會重送。

**DirectML**：程式用 Microsoft 的 DirectML 在顯示卡上跑文字辨識。它的授權條款寫明它「可能收集使用資訊並傳送給 Microsoft」（見 `THIRD_PARTY_NOTICES.txt` 裡 DirectML 的段落）。

## 檢查新版本

程式每天最多一次連到 GitHub（`api.github.com`），讀取最新正式版本的編號。只讀公開資訊，不送出任何辨識到的文字或設定；
GitHub 會看到你的 IP 位址。可以在設定裡取消「每天檢查一次有沒有新版本」。有新版本時只會通知你，不會自動下載或安裝。

## 只留在本機的資料

設定檔在 `%APPDATA%\TranslationMagicWindow\settings.json`，其餘都在 `%LOCALAPPDATA%\TranslationMagicWindow`
（啟動時用 `--data-dir` 指定的話，全部都在那個資料夾）：

| 資料 | 什麼時候產生 | 內容 |
|---|---|---|
| 設定檔 `settings.json` | 一直都有 | 設定值。金鑰用 Windows 的 DPAPI 加密，只有你的 Windows 帳號解得開 |
| 當機傾印 `dumps\*.dmp` | 程式當掉時 | 當時程式記憶體的內容，可能包含畫面上的文字。用來找出當掉的原因 |
| 記錄檔 `logs\` | 一直都有 | 程式做了什麼、花了多久。**預設不記錄辨識到的文字和譯文**（寫成「（略）」），在設定打開「詳細診斷」後才會記 |
| 專有名詞表 `glossary.txt` | 你建立的時候 | 你寫的詞 |
| 除錯傾印 `dumps\` | 你按下除錯傾印的快捷鍵時 | 當下的畫面截圖、辨識到的文字和譯文、設定（**不含金鑰**）、記錄檔。是為了回報問題用的，要不要寄給別人由你決定 |
| 擷取的畫面 `captures\` | 你按下擷取的快捷鍵，或打開「畫面穩定後自動存成 PNG」時 | 透鏡底下的畫面 |

翻譯的快取只存在記憶體裡，程式結束就消失。

## 模型和字型的下載

`tools/fetch_models` 從模型和字型的原始網站（Hugging Face、GitHub）下載檔案，下載時這些網站會看到你的 IP 位址。下載只在你執行這個工具時進行，程式本身不會自動下載。
